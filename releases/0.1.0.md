# hw_calendar 0.1.0

The first public release provides a local agenda and recurring chore calendar for Apple Silicon Macs.

## Included

- A chronological calendar with focused-day and current-day highlighting.
- Recurring chores with due lists and completion history.
- Natural-language agenda entries with confirmable structured proposals.
- Keyboard date navigation, occupied-day jumps, Flash targets, and numbered actions.
- Local notifications for confirmed reminders.
- HW Light and HW Dark interface themes.
- Portable JSON agenda export and backup-before-replace import.
- Signed in-app update checks through the stable release feed.

## Requirements

- Apple Silicon Mac.
- macOS 14 or later.

## Current limits

The application does not synchronize calendar accounts, CalDAV, EventKit, or iCalendar files. Agenda archives contain entries, proposals, and completion history. They do not contain application preferences or notification history.
