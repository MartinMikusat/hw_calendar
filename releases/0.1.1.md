# hw_calendar 0.1.1

This release migrates the Metal interface onto the terminal catalog language and adds birthday tracking.

## Included

- Terminal-style chrome: System Monospaced ink on paper, hairline frames, bracket buttons, and a 45-percent modal dim.
- Dark mode as a single `[x]` / `[ ]` Dark toggle in Settings → Styling.
- Cell-grid layout for the editor, settings, archive overlays, due tasks, and command search.
- Numbered actions with a smaller digit inside the brackets.
- Birthday create/list/due CLI commands and upcoming birthday rows in the details panel.
- Signed in-app update checks through the stable release feed.

## Requirements

- Apple Silicon Mac.
- macOS 14 or later.

## Current limits

The application does not synchronize calendar accounts, CalDAV, EventKit, or iCalendar files. Agenda archives contain entries, proposals, and completion history. They do not contain application preferences or notification history.
